# 数据层协议：CC BY-NC 4.0

以下目录属于**数据资产**，不适用根目录的 MIT 协议，而采用
**Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)**：

- `rules/`（规则库）
- `knowledge/`（知识库）
- `cases/`（案例库）
- `game_analysis/`（游戏拆解库）
- `eval/testbank/`（题库：dev / golden / canary）

含义：可共享、可改编，但必须署名，**禁止商业用途**。

理由（见 DESIGN.md §13、§26）：框架代码可以开源送人，数据层沉淀的判断标准是
本项目的核心壁垒，不送人。远期商业化时，数据层可拆分为独立私有仓库。

协议全文：https://creativecommons.org/licenses/by-nc/4.0/legalcode
